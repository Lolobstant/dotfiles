# Qu'est-ce que la Déclaration d'une fonction ?
#review #programming

La Déclaration d'une [fonction](ypvx) est l'ensemble des charactéristiques de cette fonction:
- quels paramètres et leurs types
- quel retour et son type
- quel est son identifiant (nom)

Typiquement en language C, cette déclaration se trouverait dans le fichier **Header**, alors qu'en Javascript cette déclaration se fait en même temps que sa [définition](k9qf).

La déclaration d'une fonction sert notamment dans les languages compilé a informer le compilateur de l'existance de cette fonction.
