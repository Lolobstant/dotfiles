# Qu'est-ce que la programmation fonctionnelle ?

---
tags: [#review, #programming, #fp]
---

La programmation fonctionnelle est un **paradigme** de programmation qui s'appuie sur les fonctions mathématiques pour modeler les ses propre [fonctions](ypvx-programmation-fonction.md).
**L'essence** de la programmation fonctionnelle se retrouve dans le fait qu'un **programme** est une **combinaison** d'**[expresions](bem9-programmation-fonctionnelle-expression.md)**

**Tous** les **languages** de **programmation fonctionnelle** sont basés sur le **[Lambda calculus](bxxy-lamda-calculus.md)**
